# Tech Stack

MealPrepApp este o aplicatie desktop pentru retete, gatit, planificarea meselor, stocuri, liste de cumparaturi si rapoarte nutritionale.

Clientul curent foloseste Avalonia si .NET 10, o biblioteca Core independenta de interfata si SQL Server. Clientul WPF este disponibil ca interfata Windows veche.

Consultati [prezentarea aplicatiei](../README.md), [structura proiectului](../CONTRIBUTING.md#project-layout), [referintele bazei de date](README.md) si [ghidurile platformelor](../docs/platforms/).
