# MealPrepApp 1.1.0-rc.1

This release candidate adds the meal assistant and refreshes the recipe workflow.

- Adds optional Gemini free-tier meal assistance with reviewed pantry suggestions,
  recipe imports/generation, weekly plans, and recipe/receipt photo extraction.
- Adds Android recipe editing and weekly planning with account-scoped offline drafts.
  Android 1.1.1 uses aligned Recipes, Plan, and Settings destinations with
  distinct icons. The Room 1 to 2 upgrade preserves shopping data.
- Redesigns the desktop recipe library, details, and editor. Assistant results
  open in the appropriate review tab, and the recipe save action stays visible.
- Adds private API recipe/planning routes, durable AI jobs, explicit cloud consent,
  transactional plan application, recipe provenance, and receipt retry protection.
- Adds image cropping, rotation, redaction, and metadata removal before upload.
- Keeps cloud inference disabled until a dedicated project without linked billing
  and the required private server key have been verified and configured.

Apply the ordered migrations in `release.json` through the verified-backup-first
updater, including `20261113_assistant.sql`. Deploy the API before updated clients.
Validation includes the disposable SQL suite, 88 API checks, Android Room migration,
and in-place launch of the signed 1.1.1 update. Android navigation was checked with
English, Romanian, and Russian in both themes at standard and 200% text sizes.

See [assistant setup and verification](../AI.md).
