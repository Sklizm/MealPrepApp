# MealPrepApp 1.0.0-rc.1

Candidate for the cross-platform Avalonia application and OS installation workflow.
Keep the release in draft until the required native acceptance is recorded.

## Changes

- English by default with immediate, persisted English / Russian / Romanian switching in Settings.

- Shared Avalonia interface on Windows x64, macOS Apple Silicon, and Linux x64.
- Windows setup executable with Start Menu integration, an optional desktop shortcut, upgrades, and uninstall; runtime included.
- Database connection setup before first login, with a connection test and recovery access from login and Settings.
- One maintained `main` branch with OS-specific setup/development guides. WPF remains available for legacy Windows compatibility.
- Cooking-focused redesign: warm themes, recipe filters/drafts, serving scaling, cooking timer, weekly planning, saved shopping snapshots, and explicit pantry import.

## Install

Download your platform package and `SHA256SUMS`, then compare its SHA-256 hash before installation.

- **Windows x64:** run `MealPrepApp-1.0.0-rc.1-windows-x64-setup.exe`. See the [Windows guide](../platforms/windows.md).
- **macOS Apple Silicon:** extract `MealPrepApp-macos-arm64.tar.gz` and drag `MealPrepApp.app` into Applications. See the [macOS guide](../platforms/macos.md).
- **Linux x64:** extract `MealPrepApp-linux-x64.tar.gz` and run the desktop executable. See the [Linux/NixOS guide](../platforms/linux.md).

Set the database connection on first launch using credentials from the administrator.
No deployment credentials are included. User settings survive updates and uninstall.
Packages are unsigned; macOS notarization and automatic updates are outside this candidate.
Native installation/launch acceptance must be recorded before publication.

## Database

Requires `20261028_compatibility.sql` followed by `20261028_cooking_redesign.sql`.
Installers do not provision or migrate SQL Server. For existing deployments use the
verified-backup-first upgrade instructions, rather than seed-inclusive initialization.
No schema changes are introduced by the installer/connection setup work.

See the [release procedure](README.md) for checksums, provenance, and acceptance requirements.
