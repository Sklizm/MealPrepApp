# MealPrepApp 1.1.0-rc.2

This desktop candidate refines recipe imports, review, and recovery.

- Review a photo and the original ingredient text when importing a supported
  recipe link. Save takes you to the first ingredient row that needs correction.
- Recover an interrupted save using its original request while retaining newer
  edits. Generate a fresh shopping preview before applying an edited meal plan.
- Read quantities, nutrition, and dates in your regional format. Editors retain
  exact quantities.
- Browse Pantry categories in a compact strip in short windows. Monthly reports
  show when activity is unavailable or a section is empty.

The assistant's recipe photo workflow requires the matching API and the ordered
migrations in `release.json`, including `20261119_recipe_import_photos.sql`.
Use the verified-backup-first updater for existing deployments. See
[assistant setup and verification](../AI.md).
